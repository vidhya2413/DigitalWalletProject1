**##PROBLEM STATEMENT**:
Design and implement a Java console application for a Digital Wallet system
that manages users, wallets, top-ups, transfers, payments, and statements. The application should
demonstrate object-oriented principles and ensure accurate balances.

Class Requirements: User, Wallet, TopUp, Transfer, Payment, Refund, StatementEntry

Business Rules:	
1. Top-ups increase wallet balance after confirmation.
2. Transfers require sufficient balance and update both source and destination.
3. Payments to merchants reduce balance and create statement entries.
4. Refunds credit the wallet against a valid payment.
5. Every transaction must generate a statement entry.

Menu Options: Add User / Create Wallet / Top-up / Transfer / Pay Merchant / Refund / View Statement / Exit

Expected Output:
• Show transaction receipts with amounts, fees (if any), and resulting balances.
• Show statement with chronological entries and running balance.
• Show validation errors for insufficient funds.

**##HOW TO RUN THE PROGRAM**:
1. Import the project into Eclipse.
2. Open main java.
3. Run 'Main.java' located in the 'wallet' package.
